STAGE VALUES (MeetingStage Enum)
--------------------------------------------------------------------------------
Use the string name when calling via gRPC (Postman gRPC tab):

  Value                   Integer   DB Value
  ----------------------  -------   --------------------
  STAGE_UNSPECIFIED       0         (invalid — do not use)
  STAGE_CONNECTION        1         CONNECTION
  STAGE_EXPERIENCE_DESIGN 2         EXPERIENCE_AND_DESIGN


MEETING TYPE VALUES
--------------------------------------------------------------------------------
  ONLINE
  OFFLINE


PREREQUISITES
--------------------------------------------------------------------------------
Before calling any meeting API, the lead_id must exist in the leadDetails table.

Insert a lead first:
  INSERT INTO leadDetails (lead_name, mobile, lead_type)
  VALUES ('John Doe', 9876543210, 'ADD_LEAD');

lead_type allowed values:
  SALES_POOL, EXTERNAL_LEAD, GOOGLE_ADS, META_ADS, ADD_LEAD,
  IVR_CALL, WEBSITE_LEAD, WALK_IN_LEAD, WHATSAPP

────────────────────────────────────────────────────────────────────────────────
1.1  CreateScheduled
────────────────────────────────────────────────────────────────────────────────
gRPC Method  : NotifyService/CreateScheduled
HTTP         : POST /v1/meetings/scheduled

Description  : Creates a new scheduled meeting for a lead.

Request Fields:
  Field         Type    Required  Description
  ----------    ------  --------  ------------------------------------
  lead_id       int32   YES       FK to leadDetails.lead_id
  lead_name     string  YES       Name of the lead
  title         string  NO        Meeting title
  description   string  NO        Meeting description / agenda
  meeting_date  string  YES       Date in YYYY-MM-DD format
  slot          string  YES       Time slot (e.g. "10:00 AM - 11:00 AM")
  meeting_type  string  YES       ONLINE or OFFLINE
  stage         enum    YES       STAGE_CONNECTION or STAGE_EXPERIENCE_DESIGN

Postman Message Body:
{
    "lead_id": 1,
    "lead_name": "John Doe",
    "title": "Initial Connection Call",
    "description": "First meeting with the lead to understand requirements",
    "meeting_date": "2026-07-25",
    "slot": "10:00 AM - 11:00 AM",
    "meeting_type": "ONLINE",
    "stage": "STAGE_CONNECTION"
}

Success Response:
{
    "data": {
        "id": 1,
        "lead_id": 1,
        "lead_name": "John Doe",
        "title": "Initial Connection Call",
        "description": "First meeting with the lead to understand requirements",
        "meeting_date": "2026-07-25",
        "slot": "10:00 AM - 11:00 AM",
        "meeting_type": "ONLINE",
        "stage": "STAGE_CONNECTION",
        "created_at": "2026-07-25T10:00:00+05:30"
    }
}

2.1  CreateRescheduled
────────────────────────────────────────────────────────────────────────────────
gRPC Method  : NotifyService/CreateRescheduled
HTTP         : POST /v1/meetings/rescheduled

Description  : Creates a rescheduled meeting entry for a lead.
               Reason is mandatory to explain why the meeting was rescheduled.

Request Fields:
  Field         Type    Required  Description
  ----------    ------  --------  ------------------------------------
  lead_id       int32   YES       FK to leadDetails.lead_id
  lead_name     string  YES       Name of the lead
  title         string  NO        Meeting title
  description   string  NO        Meeting description
  meeting_date  string  YES       New date in YYYY-MM-DD format
  slot          string  YES       New time slot
  meeting_type  string  YES       ONLINE or OFFLINE
  stage         enum    YES       STAGE_CONNECTION or STAGE_EXPERIENCE_DESIGN
  reason        string  YES       Reason for rescheduling

Postman Message Body:
{
    "lead_id": 1,
    "lead_name": "John Doe",
    "title": "Rescheduled Connection Call",
    "description": "Meeting rescheduled due to lead request",
    "meeting_date": "2026-07-28",
    "slot": "02:00 PM - 03:00 PM",
    "meeting_type": "ONLINE",
    "stage": "STAGE_CONNECTION",
    "reason": "Lead was unavailable on original date"
}

Success Response:
{
    "data": {
        "id": 2,
        "lead_id": 1,
        "lead_name": "John Doe",
        "title": "Rescheduled Connection Call",
        "description": "Meeting rescheduled due to lead request",
        "meeting_date": "2026-07-28",
        "slot": "02:00 PM - 03:00 PM",
        "meeting_type": "ONLINE",
        "stage": "STAGE_CONNECTION",
        "reason": "Lead was unavailable on original date",
        "created_at": "2026-07-20T14:00:00+05:30"
    }
}

4.1  CreateSuccess
────────────────────────────────────────────────────────────────────────────────
gRPC Method  : NotifyService/CreateSuccess
HTTP         : POST /v1/meetings/success

Description  : Records a successfully completed meeting outcome for a lead.

Request Fields:
  Field                 Type    Required  Description
  -------------------   ------  --------  ------------------------------------
  lead_id               int32   YES       FK to leadDetails.lead_id
  description           string  NO        Remarks / notes from the meeting
  stage                 enum    YES       STAGE_CONNECTION or STAGE_EXPERIENCE_DESIGN
  success_datetime      string  YES       RFC3339 datetime of the successful meeting
  next_action           string  YES       Next stage or action to be taken
  quote_link_generated  bool    NO        true if a quote link was generated

Postman Message Body:
{
    "lead_id": 1,
    "description": "Client showed strong interest and agreed to proceed",
    "stage": "STAGE_CONNECTION",
    "success_datetime": "2026-07-25T14:00:00Z",
    "next_action": "Move to Experience & Design stage",
    "quote_link_generated": true
}

Success Response:
{
    "data": {
        "lead_id": 1,
        "lead_name": "John Doe",
        "description": "Client showed strong interest and agreed to proceed",
        "stage": "STAGE_CONNECTION",
        "success_datetime": "2026-07-25T14:00:00Z",
        "next_action": "Move to Experience & Design stage",
        "quote_link_generated": true,

================================================================================
  DATETIME FORMAT
================================================================================

  All datetime fields must be in RFC3339 format:
    Format  : YYYY-MM-DDTHH:MM:SSZ  (UTC)
              YYYY-MM-DDTHH:MM:SS+05:30  (IST)
    Example : 2026-07-25T10:30:00Z
              2026-07-25T16:00:00+05:30
